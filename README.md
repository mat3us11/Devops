# TechFactory MiniMES

Sistema de Gestão da Produção desenvolvido para a disciplina de DevOps.

## Objetivo

Desenvolver um sistema simplificado para gerenciamento e acompanhamento da produção da empresa fictícia TechFactory.

## Funcionalidades previstas

- Cadastro de produtos
- Cadastro de máquinas
- Ordens de produção
- Registros de produção

## Tecnologias

- Python
- Flask
- Git
- GitHub

## Versão atual

0.1.0

Nesta primeira versão foi criada a estrutura inicial do projeto e uma aplicação mínima para execução local.
